# 🦆 KAPEU DUCK PET 1.0

O KAPEU DUCK PET é um patinho virtual interativo desenvolvido em Python para Windows 11. Ele anda livremente pela tela do computador, conversa, dança e interage com o usuário enquanto outros programas estão abertos.

Com fundo transparente e animações personalizadas, o patinho transforma sua área de trabalho em um ambiente mais divertido e interativo!

## ✨ Funcionalidades

- 🦆 Movimentação automática pela tela.
- 💬 Balões de conversa a cada 12 segundos.
- 🎵 Dança automática a cada 17 segundos.
- 👀 Animação dos olhos, asas e pés.
- ❤️ Sistema de carinho com corações animados.
- 🍕 Sistema de alimentação.
- 😴 Modo dormir e acordar.
- 🐾 Sistema de pulos.
- 🖱️ Modo seguir o cursor do mouse.
- ⚡ Quatro níveis de velocidade.
- 📊 Sistema de alimentação, felicidade e energia.
- 🪟 Fundo transparente e sobreposição de janelas.
- 🛠️ Menu interativo de configurações.
- 🛡️ Sistema de identificação de erros.

## 🎮 Controles

- **Botão direito:** abre o menu de opções.
- **Clique duplo:** dá carinho ao patinho.
- **Segurar e arrastar:** movimenta o patinho.
- **ESC:** fecha o programa quando a janela está em foco.

## 💻 Requisitos

- Windows 11.
- Python 3.
- Tkinter.

Não é necessário instalar bibliotecas adicionais pelo PIP.

## 🚀 Como executar

1. Baixe o arquivo Python do repositório.
2. Abra o arquivo utilizando o Python IDLE.
3. Pressione F5.
4. Divirta-se com seu novo patinho virtual!
